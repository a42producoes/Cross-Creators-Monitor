Política de Privacidade

Lumeo — Última atualização: 20 de maio de 2026

1. Sobre esta aplicação

O Lumeo (doravante "aplicação") é uma ferramenta independente de pesquisa que analisa métricas públicas de canais participantes do programa de recompensas Cross Wave (operado por NEXUS Co., Ltd.). A aplicação não é afiliada, endossada ou operada pela Cross Wave ou pela NEXUS.

2. Dados coletados

A aplicação coleta exclusivamente dados públicos através das seguintes APIs oficiais:

  • YouTube Data API v3: estatísticas públicas de canais (subscribers, total views, video count) e de vídeos (views, likes, comments count, título, descrição, data de publicação). Nenhum dado privado, autenticação OAuth ou conteúdo gerado por usuário é acessado.
  • Cross Wave API (wave-client-api.crosstoken.io): rankings públicos de campanhas, recompensas distribuídas, perfis públicos de criadores. Mesma API utilizada pelo dashboard oficial.

Os dados coletados são armazenados localmente em banco de dados SQLite para análise temporal.

3. Acesso ao dashboard

O dashboard é de acesso restrito, protegido por autenticação. Quando um usuário autorizado faz login, a aplicação registra:

  • Data e hora do acesso
  • Endereço IP aproximado (via ipapi.co) — usado apenas para localização geral (cidade/país)
  • User agent do navegador
  • Resolução de tela

Esses registros são enviados via webhook do Discord ao operador da aplicação, com finalidade de transparência (saber quem acessou e quando). Não são compartilhados com terceiros nem usados para perfilamento.

4. Compartilhamento e venda de dados

A aplicação não vende, aluga ou compartilha dados com terceiros. Os dados públicos coletados via APIs permanecem agregados internamente para análise e visualização.

5. Análise via IA (Google Gemini)

A aplicação utiliza o modelo Gemini (Google AI) para gerar resumos analíticos textuais ("dossiês") e classificar amostras de comentários públicos. Apenas dados públicos já coletados são enviados ao Gemini. Nenhuma informação pessoal identificável de usuários do dashboard é processada pela IA.

6. Cookies e armazenamento local

A aplicação utiliza localStorage do navegador apenas para:

  • Preferência de idioma (PT/EN)
  • Estado de sessão de login (não persiste credenciais)
  • Registro de primeiro acesso (carimbo de data/hora)

Nenhum cookie de rastreamento de terceiros é utilizado.

7. Direitos dos titulares de dados

Os canais analisados pela aplicação são públicos no YouTube e os dados utilizados são igualmente públicos. Caso um operador de canal deseje solicitar remoção do conjunto de canais monitorados ou apresentar contraprova sobre uma classificação, pode entrar em contato pelos meios listados abaixo.

8. Conformidade com termos de terceiros

A aplicação opera em conformidade com:

  • YouTube API Services Terms of Service
  • Google Privacy Policy
  • Termos de uso da Cross Wave (consulta a endpoints públicos sem autenticação)

9. Contato

Para questões sobre privacidade, dados ou contestações de análise:

  • Canal YouTube do operador: Antena 42
  • Cross Wave profile: Antena 42 na Cross Wave

10. Alterações nesta política

Esta política pode ser atualizada conforme a aplicação evolui. A data da última atualização está sempre no topo. Mudanças materiais serão comunicadas no próprio dashboard.

Privacy Policy

Lumeo — Last updated: May 20, 2026

1. About this application

The Lumeo (the "application") is an independent research tool that analyzes public metrics of channels participating in the Cross Wave creator rewards program (operated by NEXUS Co., Ltd.). The application is not affiliated with, endorsed by, or operated by Cross Wave or NEXUS.

2. Data collected

The application collects only public data through the following official APIs:

  • YouTube Data API v3: public channel statistics (subscribers, total views, video count) and video statistics (views, likes, comment count, title, description, publish date). No private data, OAuth authentication, or user-generated content is accessed.
  • Cross Wave API (wave-client-api.crosstoken.io): public campaign rankings, distributed rewards, public creator profiles. The same API used by the official dashboard.

Collected data is stored locally in a SQLite database for temporal analysis.

3. Dashboard access

The dashboard is access-restricted, protected by authentication. When an authorized user logs in, the application records:

  • Date and time of access
  • Approximate IP address (via ipapi.co) — used only for general location (city/country)
  • Browser user agent
  • Screen resolution

These records are sent via Discord webhook to the application operator for transparency purposes (knowing who accessed and when). They are not shared with third parties or used for profiling.

4. Data sharing and sale

The application does not sell, rent, or share data with third parties. Public data collected via APIs is kept internally aggregated for analysis and visualization.

5. AI analysis (Google Gemini)

The application uses the Gemini model (Google AI) to generate textual analytical summaries ("dossiers") and classify samples of public comments. Only already-collected public data is sent to Gemini. No personally identifiable information about dashboard users is processed by the AI.

6. Cookies and local storage

The application uses browser localStorage only for:

  • Language preference (PT/EN)
  • Login session state (does not persist credentials)
  • First-access timestamp

No third-party tracking cookies are used.

7. Data subject rights

Channels analyzed by the application are public on YouTube, and the data used is similarly public. If a channel operator wishes to request removal from the monitored set or submit counter-evidence regarding a classification, they can contact the operator via the channels listed below.

8. Compliance with third-party terms

The application operates in compliance with:

  • YouTube API Services Terms of Service
  • Google Privacy Policy
  • Cross Wave terms of use (public endpoint queries without authentication)

9. Contact

For privacy questions, data inquiries, or classification disputes:

  • Operator's YouTube channel: Antena 42
  • Cross Wave profile: Antena 42 on Cross Wave

10. Changes to this policy

This policy may be updated as the application evolves. The last update date is always shown at the top. Material changes will be communicated within the dashboard itself.
