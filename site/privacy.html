Política de Privacidade

Lumeo — Última atualização: 20 de maio de 2026

1. Sobre o Lumeo

O Lumeo (doravante "aplicação") é uma ferramenta independente de análise forense de engajamento em plataformas públicas. Sua função é avaliar a integridade de métricas públicas de criadores de conteúdo a partir de dados acessíveis via APIs oficiais. A aplicação é desenvolvida e operada de forma independente, sem afiliação a qualquer plataforma específica.

2. Dados coletados

A aplicação coleta exclusivamente dados públicos a partir de APIs oficiais. No momento, a fonte primária é:

  • YouTube Data API v3: estatísticas públicas de canais (inscritos, total de views, contagem de vídeos) e de vídeos (views, likes, contagem de comentários, título, descrição, data de publicação). Nenhum dado privado, autenticação OAuth ou conteúdo gerado por usuário é acessado.

A aplicação pode integrar-se a APIs públicas adicionais de plataformas que operem programas de recompensa para criadores. Toda integração é exclusivamente de leitura e baseada em endpoints públicos. Os dados coletados são armazenados localmente em banco de dados para análise temporal.

3. Acesso ao dashboard

O dashboard é de acesso restrito, protegido por autenticação. Quando um usuário autorizado faz login, a aplicação registra:

  • Data e hora do acesso
  • Endereço IP aproximado (via ipapi.co) — usado apenas para localização geral (cidade/país)
  • User agent do navegador
  • Resolução de tela

Esses registros são enviados ao operador da aplicação com finalidade de auditoria e transparência (saber quem acessou e quando). Não são compartilhados com terceiros nem usados para perfilamento ou marketing.

4. Compartilhamento e venda de dados

A aplicação não vende, aluga ou compartilha dados com terceiros. Os dados públicos coletados via APIs permanecem agregados internamente para análise e visualização.

5. Análise via Inteligência Artificial

A aplicação utiliza o modelo Gemini (Google AI) para gerar resumos analíticos textuais ("dossiês") e classificar amostras de comentários públicos. Apenas dados públicos já coletados são processados pela IA. Nenhuma informação pessoal identificável de usuários do dashboard é enviada para análise por modelos de IA.

6. Cookies e armazenamento local

A aplicação utiliza localStorage do navegador apenas para:

  • Preferência de idioma (PT/EN)
  • Estado de sessão de login (não persiste credenciais)
  • Registro de primeiro acesso (carimbo de data/hora)

Nenhum cookie de rastreamento de terceiros é utilizado.

7. Direitos dos titulares de dados

Os canais analisados pela aplicação são públicos e os dados utilizados são igualmente públicos. Caso um operador de canal deseje solicitar remoção do conjunto monitorado ou apresentar contraprova sobre uma classificação atribuída, pode entrar em contato pelos meios listados abaixo. A aplicação reconhece o direito de resposta e revisão de classificação mediante apresentação de evidências objetivas.

8. Conformidade com termos de terceiros

A aplicação opera em conformidade com:

  • YouTube API Services Terms of Service
  • Google Privacy Policy
  • Termos de uso das demais plataformas das quais consulta dados públicos

9. Contato

Para questões sobre privacidade, dados ou contestações de análise, entre em contato através do canal operacional da aplicação.

10. Alterações nesta política

Esta política pode ser atualizada conforme a aplicação evolui. A data da última atualização está sempre no topo. Mudanças materiais serão comunicadas no próprio dashboard.

Privacy Policy

Lumeo — Last updated: May 20, 2026

1. About Lumeo

Lumeo (the "application") is an independent forensic engagement analysis tool for public platforms. Its purpose is to evaluate the integrity of public engagement metrics for content creators using data accessible via official APIs. The application is developed and operated independently, with no affiliation to any specific platform.

2. Data collected

The application collects only public data from official APIs. The primary source is currently:

  • YouTube Data API v3: public channel statistics (subscribers, total views, video count) and video statistics (views, likes, comment count, title, description, publish date). No private data, OAuth authentication, or user-generated content is accessed.

The application may integrate with additional public APIs of platforms operating creator reward programs. All integrations are strictly read-only and based on public endpoints. Collected data is stored locally in a database for temporal analysis.

3. Dashboard access

The dashboard is access-restricted, protected by authentication. When an authorized user logs in, the application records:

  • Date and time of access
  • Approximate IP address (via ipapi.co) — used only for general location (city/country)
  • Browser user agent
  • Screen resolution

These records are sent to the application operator for audit and transparency purposes (knowing who accessed and when). They are not shared with third parties or used for profiling or marketing.

4. Data sharing and sale

The application does not sell, rent, or share data with third parties. Public data collected via APIs is kept internally aggregated for analysis and visualization.

5. AI-powered analysis

The application uses the Gemini model (Google AI) to generate textual analytical summaries ("dossiers") and classify samples of public comments. Only already-collected public data is processed by the AI. No personally identifiable information about dashboard users is sent for processing by AI models.

6. Cookies and local storage

The application uses browser localStorage only for:

  • Language preference (PT/EN)
  • Login session state (does not persist credentials)
  • First-access timestamp

No third-party tracking cookies are used.

7. Data subject rights

Channels analyzed by the application are public, and the data used is similarly public. If a channel operator wishes to request removal from the monitored set or submit counter-evidence regarding an assigned classification, they may contact us via the operational channel listed below. The application recognizes the right of response and classification review upon submission of objective evidence.

8. Compliance with third-party terms

The application operates in compliance with:

  • YouTube API Services Terms of Service
  • Google Privacy Policy
  • Terms of service of other platforms whose public data is queried

9. Contact

For privacy questions, data inquiries, or classification disputes, please contact us through the operational channel of the application.

10. Changes to this policy

This policy may be updated as the application evolves. The last update date is always shown at the top. Material changes will be communicated within the dashboard itself.
