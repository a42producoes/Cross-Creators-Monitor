⚠️ Disclaimer de relacionamento e metodologia

Metodologia: Dados coletados via APIs públicas do YouTube Data API v3 e da própria Cross Wave (mesma API usada pelo dashboard oficial). Análise baseada em critérios matemáticos objetivos: razão Views/Subscribers, like ratio, detecção de anomalias temporais (degraus de views, remoções confirmadas pelo YouTube, like-bombs), comparação campanha vs baseline orgânico do próprio canal. Classificação por regras determinísticas + análise contextual via Gemini.

Limitações conhecidas: Apenas vídeos de YouTube (TikTok fora do escopo). Apenas top 25 de cada campanha ativa monitorado. Coleta a cada 2h pode perder eventos entre snapshots.
